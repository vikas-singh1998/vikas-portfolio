# Senior Frontend Portfolio

A production-ready portfolio web application built with React, Vite, TypeScript, Tailwind CSS, and shadcn-style UI primitives.

## Stack

- React + Vite
- TypeScript
- Tailwind CSS
- shadcn/ui-style component architecture with Radix primitives
- React Router
- React Hook Form + Zod
- Framer Motion
- Recharts

## Run

```bash
npm install
npm run dev
```

## Included Features

- Multi-page portfolio with routing
- Premium landing page and responsive layout
- Projects listing with tech filters
- Dynamic project detail routes
- Contact form with validation
- Command palette (`Cmd/Ctrl + K`)
- Light and dark theme toggle
- Scroll progress indicator
- Lazy-loaded routes
- SEO-friendly metadata updates
